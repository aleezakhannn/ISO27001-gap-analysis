# MicroFinCo ISO 27001 Gap Analysis

A fictional gap analysis comparing MicroFinCo's sample security processes against the ISO/IEC 27001 Annex A control set. It records the implementation status of each control and notes the evidence found or the artefact that is missing.

## File

- [iso27001_gap_analysis.csv](iso27001_gap_analysis.csv)

## Columns

| Column | Description |
|---|---|
| Control ID | Annex A control number (e.g. A.9.2.3) |
| Control Name | Name of the control |
| Status | Implemented, Partial, or Not |
| Evidence Note | Short note on the evidence or what is missing |

## Summary

- **Controls evaluated:** 35
- **Implemented:** 14
- **Partial:** 14
- **Not:** 7
- **Numbering:** ISO 27001:2013 Annex A

## Method

1. Reviewed the public ISO 27001 Annex A control list.
2. Invented a sample set of MicroFinCo security artefacts (policies, configuration files, logs).
3. Mapped each control to those artefacts and assigned a status.
4. Recorded the results and short evidence notes in the CSV.

## Note

Training exercise only. MicroFinCo and all evidence are fictional.
